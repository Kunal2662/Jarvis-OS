# Architecture Diagrams

Store `.png`, `.svg` and `.drawio` files here.

Recommended tools:

* [draw.io / diagrams.net](https://app.diagrams.net) — commit both `.drawio`
  source and exported `.png`.
* [Excalidraw](https://excalidraw.com) — commit `.excalidraw` + PNG.
* [Mermaid](https://mermaid.js.org) — embed inline in `docs/*.md`.
